KOHINOOR ADVANCE PLUS — GITHUB PAGES + GOOGLE APPS SCRIPT + LEADVERTEX

This version uses the same architecture as the FlexComfort project:
GitHub Pages (index.html) -> Google Apps Script Web App -> LeadVertex CRM.
No PHP hosting is required. The old PHP files were removed from this package.

LEADVERTEX VALUES PRESERVED FROM THE ORIGINAL PROJECT
- Project: kohinoorplus
- Webmaster ID: 28
- Good ID: 184285
- Product price sent to CRM: 2690
- Quantity: 1

1. CREATE THE GOOGLE APPS SCRIPT
- Open https://script.google.com/ and create a New project.
- Replace the contents of Code.gs with the complete contents of LeadVertex-Google-Apps-Script.gs.
- Open Project Settings -> Script Properties and add:
  LEADVERTEX_PROJECT = kohinoorplus
  LEADVERTEX_WEBMASTER_ID = 28
  LEADVERTEX_TOKEN = YOUR_NEW_LEADVERTEX_API_TOKEN
  LEADVERTEX_GOOD_ID = 184285
  LEADVERTEX_PRODUCT_PRICE = 2690
- Save. Do not put the API token in index.html or GitHub.

2. DEPLOY AS WEB APP
- Deploy -> New deployment -> select Web app.
- Execute as: Me.
- Who has access: Anyone.
- Deploy and complete authorization.
- Copy the URL ending in /exec.

3. CONNECT THE WEBSITE
- Open index.html.
- Find PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE.
- Replace it with your deployed Apps Script /exec URL.
- Commit/push the updated files to GitHub.

4. ENABLE GITHUB PAGES
- In GitHub repository: Settings -> Pages.
- Select Deploy from a branch, branch main, folder /(root), then Save.
- Wait for GitHub Pages to publish the website.

5. TEST
- Submit one real test order using your own phone/address.
- Confirm the order appears in LeadVertex -> Orders.
- If it fails, open Apps Script -> Executions and inspect the latest execution log.
- If Apps Script code changes later, Deploy -> Manage deployments -> Edit -> select New version -> Deploy.

IMPORTANT
- The previous leadvertex-settings.php file contained a credential. It has been removed from this package. Rotate/revoke that old LeadVertex token and use a new token only in Script Properties.
- Check that Webmaster 28 has permission to create orders and Good ID 184285 is active/available.
- GitHub Pages serves static files; Google Apps Script performs the server-side CRM request.
- This bridge follows the same general flow as FlexComfort, but its CRM project, Good ID and price remain Kohinoor's values.
